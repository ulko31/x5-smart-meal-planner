# X5 Smart Meal Planner

Продуктовый кейс по созданию встроенного сервиса для рационального планирования питания внутри экосистемы X5.

Основная идея — создать AI-ассистента, который помогает пользователю выбрать, что и где поесть, исходя из его местоположения, бюджета, предпочтений, времени и доступных предложений X5.

Сервис объединяет онлайн- и офлайн-каналы компании и превращает выбор еды из отдельной задачи в персонализированный пользовательский сценарий.

## Задача

Разработать цифровой сервис, который:

- сокращает время на выбор еды;
- помогает рациональнее планировать питание;
- учитывает бюджет пользователя;
- использует персональные предпочтения;
- объединяет сервисы экосистемы X5;
- повышает лояльность;
- увеличивает средний чек;
- стимулирует кросс-продажи;
- создаёт дополнительную ценность для X5.

## Продуктовая концепция

Сервис представляет собой AI-ассистента, который получает пользовательский запрос и подбирает наиболее удобный сценарий питания.

Пользователь может ввести запрос:

- текстом;
- голосом;
- через конструктор.

## Пользовательские данные

Для формирования рекомендации учитываются:

- местоположение;
- время;
- дата;
- тип приёма пищи;
- бюджет;
- предпочтения;
- кухня;
- диета;
- ограничения;
- цель.

Например:

```text
Где:
офис

Когда:
13:00

Что:
полноценный обед

Бюджет:
до 700 ₽

Предпочтения:
азиатская кухня
```

После этого ассистент анализирует доступные варианты.

## Логика AI-ассистента

Сервис может предложить:

- готовую еду из ближайшего магазина;
- доставку;
- самовывоз;
- оптимальный маршрут;
- блюдо по акции;

- альтернативу с более выгодной ценой.

Основная идея:

> пользователь не ищет вручную между несколькими приложениями и магазинами — сервис сам предлагает оптимальный сценарий.
